# 🔤 ASCII Text Analyzer

> A tiny C++ command-line utility that converts every character in your input into its **ASCII value**.

---

## ✨ Features

- ⌨️ Accepts a complete line of text
- 🔢 Displays the ASCII value of every character
- ␠ Handles spaces clearly
- 📊 Shows the total character count
- ⚡ Lightweight — no external libraries required

---

## 🖥️ Example

```text
====================================
        ASCII TEXT ANALYZER
====================================
Enter text: Hello World

Character    ASCII
------------------
H            72
e            101
l            108
l            108
o            111
Space        32
W            87
o            111
r            114
l            108
d            100

Total characters: 11
```

## 🚀 Run Locally

### Compile

```bash
g++ main.cpp -o ascii-analyzer
```

### Run

```bash
./ascii-analyzer
```

### Windows

```bash
g++ main.cpp -o ascii-analyzer.exe
ascii-analyzer.exe
```
